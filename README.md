# Ethical Chatbot – Data Ethics Awareness Tool

An interactive Telegram chatbot designed to educate users on data ethics through real-world scenarios, quizzes, and reflective prompts. Built using Python and the Telegram Bot API, this project aims to make ethical learning accessible and engaging for students, professionals, and the general public.

---

## Overview

As data becomes increasingly embedded in everyday decision-making, ethical awareness is crucial. This chatbot simulates ethical dilemmas in data science and prompts users to think critically about key concepts such as:

- Data Privacy
- Fairness & Bias
- Consent
- Transparency
- Responsible AI Use

The bot offers:
- Yes/No/Unsure decision-based scenarios
- Reflection-based follow-up questions
- Quiz mode to reinforce learning

---

## Technologies Used

- **Python 3.8+**
- **Telegram Bot API**
- **Python-Telegram-Bot Library**

---

## Features

- **Interactive Scenarios**: Users respond to dilemmas and explore consequences.
- **Reflection Prompts**: Follows up user choices with thought-provoking questions.
- **Quiz Mode**: Multiple-choice questions on ethical principles.
- **Modular Design**: Easy to expand with new scenarios and quizzes.
- **Accessible Language**: Designed for clarity and inclusiveness.

## Setup Instructions

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Chandravadan30/ethical-chatbot.git
   cd ethical-chatbot
````

2. **Install Dependencies**

   ```bash
   pip install -r requirements.txt
   ```

3. **Set Up Telegram Bot**

   * Talk to [@BotFather](https://t.me/botfather) on Telegram to create a bot and get your API token.
   * Replace `YOUR_BOT_TOKEN` in `bot.py` with your actual token.

4. **Run the Bot**

   ```bash
   ethical_chatbot.py
   ```

---

##Commands

* `/start` – Begin conversation
* `/scenario` – View an ethical dilemma
* `/quiz` – Take a quiz on data ethics
